# 업무 종합 관리 — 파일 분리 구조

원본 `index.html` 하나(약 9,000줄)에 몰려있던 코드를, 내비게이션 독의 카테고리 기준으로
`css/`, `js/` 폴더 아래 파일별로 나눴습니다. **`index.html`은 이 파일들을 그대로 조합해서
만든 최종 결과물이며, 원본과 100% 동일하게 동작합니다** (분리 후 재조합한 내용을 원본과
한 글자도 다르지 않게 diff로 검증했습니다).

## 폴더 구조

```

├── head-top.html        ← <head> 상단 (meta, 외부 CDN 스크립트)
├── body.html             ← <body> 골격 (레이아웃 껍데기)
├── css/
│   ├── 00-variables.css      공통 색상/여백 변수, 다크·라이트 테마
│   ├── 01-shell-nav.css      좌측 내비게이션 독, 토스트, 모바일 공통
│   ├── 02-home.css           홈 화면
│   ├── 03-login.css          로그인 화면
│   ├── 04-calendar.css       캘린더 페이지
│   ├── 05-notes.css          업무 정리(메모) 페이지
│   ├── 06-agents.css         상담사 관리 페이지
│   ├── 07-interviews.css     면담일지 페이지
│   ├── 08-agent-qa-preview.css  상담사 상세 내 QA 미리보기
│   ├── 09-schedule.css       월별 스케줄 페이지
│   ├── 10-qa.css             품질 관리(QA) 페이지
│   └── 11-overrides.css      공통 마감 스타일
└── js/
    ├── 01-common.js   로그인/계정/클라우드 동기화/테마/백업/되돌리기 등 공통 로직
    ├── 02-calendar.js 캘린더 + 할 일(Todo)
    ├── 03-notes.js    업무 정리(메모)
    ├── 04-agents.js   상담사 관리
    ├── 05-qa.js       품질 관리(QA)
```

## CSS와 JS를 다르게 다룬 이유

- **CSS**는 `<link rel="stylesheet">` 태그로 각 파일을 그대로 불러오기만 하면 되므로,
  파일을 수정한 뒤 `index.html`을 새로고침하면 바로 반영됩니다. 빌드가 필요 없습니다.
- **JS**는 그렇지 않습니다. 이 앱은 로그인 직후 Supabase 클라우드 동기화를
  `await`으로 순서를 맞춰 처리하고, 그 뒤를 이어 계정/할일/상담사/스케줄 등
  각 페이지의 데이터를 순서대로 불러오는 구조예요. 만약 `js/*.js` 파일들을
  각각 독립된 `<script src>`로 따로 불러오면 이 실행 순서가 깨져서
  "동기화 전에 화면부터 그려지는" 등의 오류가 날 수 있습니다.
  그래서 `js/` 파일들은 **원래 순서 그대로 이어붙여 하나의 스크립트로 묶어서
  실행**하도록 만들었고, 그 조합 작업을 `build.js`가 대신 해줍니다.

## 사용 방법

- **그냥 열기**: `index.html`을 열면 바로 원본과 동일하게 동작합니다. (다른 파일들과 폴더
  구조를 그대로 유지한 채로 옮기세요 — `css/`, `js/` 폴더가 `index.html`과 같은 위치에
  있어야 합니다.)
- **코드를 수정하고 싶을 때**:
  1. 수정하려는 카테고리의 파일만 열어서 편집합니다. (예: 캘린더 관련 수정 → `js/02-calendar.js`, `css/04-calendar.css`)
  2. CSS만 고쳤다면 `index.html`을 새로고침하면 바로 반영됩니다.
  3. JS를 고쳤다면, Node.js가 설치되어 있는 컴퓨터에서 이 폴더 안에 들어가 아래 명령을
     한 번 실행해 `index.html`을 다시 만들어야 합니다.
     ```
     node build.js
     ```
     (Node.js가 없다면 저에게 다시 파일을 올려주시면 같은 방식으로 다시 조합해드릴게요.)

## 주의

`css/06-agents.css`, `css/07-interviews.css`, `css/08-agent-qa-preview.css`처럼
경계가 딱 떨어지지 않는 몇몇 파일은 실제 화면 구성상 인접한 스타일이 조금 섞여
있을 수 있어요(예: 상담사 상세 화면의 QA 미리보기 스타일은 별도 파일로 뺐습니다).
동작에는 전혀 영향이 없고, 순수하게 파일을 어떻게 나눴는지에 대한 참고 사항입니다.
